寮 求人 名古屋 LP
==================

ファイル構成
- index.html
- styles.css
- script.js

公開方法
1. 3ファイルを同じ階層の公開ディレクトリへアップロードしてください。
2. GitHub Pagesの場合はリポジトリ直下に配置してPagesを有効化してください。
3. Xserverの場合は対象ドメインの public_html 配下へ配置してください。

LINEリンク
現在は https://lin.ee/xo4sCJy を設定しています。
変更する場合は index.html 内の該当URLを一括置換してください。

画像
Unsplashの外部画像URLを使用しています。画像を自社素材へ差し替える場合は styles.css の
.visual-photo / .job-thumb-1 / .job-thumb-2 / .job-thumb-3 の background-image を変更してください。

重要
- 求人カードは「モデル例」として作成しているため、実在求人を掲載する場合は実際の雇用条件へ変更してください。
- 生活支援金10万円は支給条件を明示してください。
- 運営会社・プライバシーポリシー・許可番号等は公開前に実情報へ差し替えてください。
